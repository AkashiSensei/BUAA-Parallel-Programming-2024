# 课程提供的辅助代码

此目录保留教学示例，用于理解和复习，不标为学生独立项目。

| 目录 | 原始来源 | 内容 |
| --- | --- | --- |
| `mpi/` | 课程 `chapter3.zip` | MPI 通信、积分、矩阵向量运算、奇偶排序等 |
| `pthreads/` | 课程 Pthreads 示例目录 | 线程、互斥量、读写锁、条件变量、信号量、链表等 |
| `openmp/` | 课程 OpenMP 示例目录 | parallel/for、调度、归约、共享变量及消息队列等 |
| `mpi-tsp-nbody/` | 课程第 6 章源码附件 | TSP、N-body、相关辅助源码 |
| `cuda-eigenfaces/` | 课程 eigenfaces 附件 | CUDA 特征脸相关样例；部分外部数据需自行准备 |
| `mpi-hello/` | 本地 MPI 环境测试小包 | 来源未明确的 Hello World 示例 |

原注释和版权声明保留。原始编译产物、目标文件和输出日志不收入；CUDA 大作业供检查器使用的课程参考二进制另在 `final-cuda/` 明确标注保留。
