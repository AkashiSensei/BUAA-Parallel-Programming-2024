# 课程参考材料

这些参考目录按主题组织，**均为课程提供或来源未明确的示例，没有找到作者独立提交或报告**。它们与编号编程作业分开标注，避免把教学代码当作个人课设成果。

| 参考主题 | 来源 | 内容 |
| --- | --- | --- |
| [MPI 课程示例](reference-mpi-examples/) | 课程 chapter3 附件与本地 MPI 环境测试小包 | 积分、通信、矩阵向量运算、排序等；`support/chapter3/` 保存课程附件，`support/hello-local/` 保存来源未明确的本地 Hello World 示例 |
| [Pthreads 课程示例](reference-pthreads-examples/) | 课程 Pthreads 示例目录 | 线程、互斥量、读写锁、条件变量、信号量和链表等 |
| [OpenMP 课程示例](reference-openmp-examples/) | 课程 OpenMP 示例目录 | 并行循环、归约、变量作用域、积分及消息队列等 |
| [TSP / N-body 参考任务](reference-tsp-nbody/) | 课程第 6 章源码附件 | MPI、Pthreads、OpenMP 的 TSP / N-body 例程及辅助代码 |
| [CUDA eigenfaces 参考任务](reference-cuda-eigenfaces/) | 课程 eigenfaces 附件 | 特征脸相关 CUDA 示例和数据转换脚本；外部图像数据需另行准备 |

原编译产物和日志未收入。CUDA 大作业框架与参考二进制另放在 `final-cuda/`，并标明来自课程。
